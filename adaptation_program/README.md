# 각색 프로그램

네이버 블로그 원고를, 실제 블로거가 제품을 써보고 느낀 장점을 신뢰감 있게 풀어낸
정보성 글로 각색해주는 CLI 도구입니다. SEO(네이버 C-Rank·D.I.A+)·AEO(질문-답변 구조)·
GEO(AI 인용 최적화)를 함께 적용하고, 의약품 오인/과대광고 표현을 자동 차단합니다.

화자 페르소나(40대 여성, 무역회사 재직, 수영·헬스·PT, 매일 야채·과일 섭취, 교회 집사 등)가
`adapt.py`의 시스템 프롬프트에 고정 배경 설정으로 내장되어 있어, 정보성 글과 제품 리뷰 모두에서
글의 주제와 자연스럽게 맞을 때만 선택적으로 녹여냅니다(자녀 관련 내용은 어떤 형태로도 언급하지 않음).

## 설치

```bash
cd adaptation_program
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # Anthropic API 키 설정
```

## 사용법

```bash
python adapt.py 원고.txt -g 제품가이드.txt -p "제품명" -k "키워드1, 키워드2" -o 결과.txt
```

`원고.txt`(위치 인자)와 `-g/--guide`는 역할이 다릅니다.
- `원고.txt`: 문체·구성만 참고하는 예시글 (사실 근거로 쓰지 않음)
- `-g/--guide` (**필수**): 특허·원료명·성분표·함량·기능성 문구·포장 등 제품에 대한 모든
  구체적 사실의 유일한 근거가 되는 공식 제품 가이드/상세페이지 텍스트. 이 파일에 없는
  수치나 성분은 지어내지 않습니다. `-g` 없이 실행하면 바로 에러로 중단됩니다.

원고는 파일 없이 붙여넣기도 가능합니다(`-g`는 여전히 필수):

```bash
python adapt.py -g 제품가이드.txt
# 원고 내용을 붙여넣고 Ctrl+D
```

### 옵션

| 옵션 | 설명 | 기본값 |
| --- | --- | --- |
| `input` | 참고할 원고/예시글 파일 경로 (생략 시 표준입력, 문체·구성만 참고) | - |
| `-g`, `--guide` | **[필수]** 제품 필수 가이드 파일 경로 (제품 사실 정보의 유일한 근거) | - (미지정 시 에러) |
| `-p`, `--product` | 제품명 | - |
| `-k`, `--keywords` | 본문에 녹일 핵심 키워드 (쉼표 구분) | - |
| `--sponsored` | 협찬/제공받은 홍보 글이면 지정 (협찬 표시 문구 자동 삽입) | 미지정 |
| `-o`, `--output` | 결과 저장 파일 경로 (생략 시 화면 출력) | - |
| `-m`, `--model` | 사용할 Claude 모델 | `claude-sonnet-5` |
| `-t`, `--temperature` | 창의성 정도 0.0~1.0 (매번 다른 글이 나오도록 기본 1.0) | `1.0` |

## 출력 형식

결과는 하나의 문서로 이어지며, `[네이버 AI 브리핑 & 메인 노출 최적화 CTR 추천 제목 20개]`
헤더를 기준으로 게시용 본문과 참고용 정보로 나뉩니다.

1. **게시용 본문** — 네이버 블로그에 그대로 복사해서 게시할 수 있는 부분.
   - 도입부(제목 없이 바로 시작) → `[목차]`(5단계 흐름: 대상·계기 → 정의 → 팩트/데이터 →
     결핍·문제 제기 → 실전 후기) → 본문(각 소제목은 매번 새롭게 창작하는 `"인용구"` 형태) →
     `---` → `[AI 브리핑 요약데이터 목차]` → `※`로 시작하는 면책문구 2~3줄 →
     `[네이버 AI 브리핑 최적화 연관 해시태그]`(8~10개), 전부 필수 포함
   - 본문은 "정보단"(도입부+①~④)과 "제품단"(⑤ 실전 후기)으로 나뉘며, 분량 비율은 항상
     **정보단 70% : 제품단 30%**로 배분됩니다. **정보단(도입부, ①~④)에는 제품명·브랜드명이
     절대 등장하지 않고** 순수 일반 정보만 다루며, 제품은 오직 제품단(⑤)에서만 등장해
     페르소나를 풍성하게 담은 "찐후기"로 작성됩니다.
   - 한 줄 14~22자, 한 문단 4~6줄로 모바일 가독성에 맞춰 줄바꿈 (가운데 정렬은 네이버 에디터에서 직접 적용)
   - 공백 포함 2000자 이내 — 단, `[목차]`와 `[AI 브리핑 요약데이터 목차]` 섹션은 이 글자 수 제한에 포함되지 않음
2. **참고용 정보** (`[네이버 AI 브리핑 & 메인 노출 최적화 CTR 추천 제목 20개]` 헤더부터) — 게시글에는 넣지 않음.
   - CTR 높은 제목 후보 20개 (이 중 하나를 골라 네이버 에디터 제목란에 입력)
   - `[부록: SEO · AEO · GEO 통합 메타데이터 분석]` — SEO 키워드 분산/LSI 키워드,
     AEO 답변 스냅샷(Q&A), GEO 인용 블록

## 안전장치 (네이버 정지·스팸·불법 콘텐츠 규정 반영)

- 제품 필수 가이드는 오직 "제품단"(⑤ 실전 후기)에서만 사용합니다. 정보단(도입부, ①~④)에는
  제품명이나 가이드 내용이 전혀 등장하지 않습니다. 제품단에서 언급하는 구체적 사실(특허,
  원료명, 성분·함량, 기능성 문구, 포장 등)은 반드시 `-g/--guide`로 제공한 내용에서만
  가져오고, 가이드에 없는 내용은 지어내지 않습니다.
- 실행할 때마다 도입부/전개 방식/소제목 표현을 다르게 유도해 매번 다른 글이 나오도록 합니다.
- "완치", "치료된다", "낫는다", "특효", "항암효과", "탈모치료" 등 식약처 부당광고 금지 표현이
  감지되면 실행 후 경고 메시지를 출력합니다(면책문구 자체는 검사에서 제외). **경고가 없어도
  게시 전에는 반드시 직접 검수해주세요.**
- `[목차]`/`[AI 브리핑 요약데이터 목차]` 섹션을 제외한 본문 글자 수가 2000자를 초과하면 경고를 출력합니다.
- `[목차]`, `[AI 브리핑 요약데이터 목차]`, 제목 후보 20개, SEO·AEO·GEO 부록 섹션이 누락되면 경고를 출력합니다.
- `-k`로 지정한 키워드는 1개든 5개든 전부 본문에서 충분히(문단 단위로) 다뤄지도록 지시하며,
  본문에 아예 없거나 1번만 언급된 키워드가 있으면 경고를 출력합니다(네이버 인플루언서 키워드 적합성 대응).
- 원본성 보장: 원고를 그대로 복사하지 않고 문장·구조를 완전히 재창작해 네이버가 "유사 문서"로
  판정할 소지를 줄입니다. 키워드 남용(스터핑), 낚시성 제목, 과도한 연락처/링크 반복 등
  저품질·스팸 판정 요인도 피하도록 지시합니다.
- `--sponsored` 지정 시, 공정거래위원회 "추천·보증 등에 관한 표시·광고 심사지침"에 따라
  협찬/제공 사실을 눈에 잘 띄는 위치에 명확한 국문 문구로 표시합니다(뒷광고 금지 규정 대응).
- 이 도구는 초안 생성을 도울 뿐이며, 의료/건강 관련 문구·협찬 표시·최종 게시물의 법적 책임은
  게시자 본인에게 있습니다. 특히 네이버의 정확한 저품질/스팸 판정 알고리즘은 공식적으로
  공개되어 있지 않으므로, 게시 전 최종 검수는 필수입니다.
