# 각색 프로그램

네이버 블로그 원고를, 실제 블로거가 제품을 써보고 느낀 장점을 신뢰감 있게 풀어낸
정보성 글로 각색해주는 CLI 도구입니다. SEO(네이버 C-Rank·D.I.A+)·AEO(질문-답변 구조)·
GEO(AI 인용 최적화)를 함께 적용하고, 의약품 오인/과대광고 표현을 자동 차단합니다.

## 설치

```bash
cd adaptation_program
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...   # Anthropic API 키 설정
```

## 사용법

```bash
python adapt.py 원고.txt -p "제품명" -k "키워드1, 키워드2" -o 결과.txt
```

파일 없이 붙여넣기:

```bash
python adapt.py
# 원고 내용을 붙여넣고 Ctrl+D
```

### 옵션

| 옵션 | 설명 | 기본값 |
| --- | --- | --- |
| `input` | 참고할 원고/예시글 파일 경로 (생략 시 표준입력) | - |
| `-p`, `--product` | 제품명 | - |
| `-k`, `--keywords` | 본문에 녹일 핵심 키워드 (쉼표 구분) | - |
| `-o`, `--output` | 결과 저장 파일 경로 (생략 시 화면 출력) | - |
| `-m`, `--model` | 사용할 Claude 모델 | `claude-sonnet-5` |
| `-t`, `--temperature` | 창의성 정도 0.0~1.0 (매번 다른 글이 나오도록 기본 1.0) | `1.0` |

## 출력 형식

결과는 두 부분으로 나뉩니다.

1. **본문** — 네이버 블로그에 그대로 복사해서 게시할 수 있는 최종본.
   - 제목 → `"목차"` → 본문(소제목은 매번 새롭게 창작하는 `"인용구"` 형태) → `"요약"` →
     `법적 고지:`로 시작하는 법적 고지문 → `#해시태그`(4~5개) 순서, 전부 필수 포함
   - 한 줄 14~22자, 한 문단 4~6줄로 모바일 가독성에 맞춰 줄바꿈 (가운데 정렬은 네이버 에디터에서 직접 적용)
   - 공백 포함 2000자 이내 — 단, `"목차"`와 `"요약"` 섹션은 이 글자 수 제한에 포함되지 않음
2. **`=====참고용 정보 (게시글 본문 아님)=====`** 구분선 아래 — 게시글에는 넣지 않는 SEO 참고자료.
   - 본문에 녹인 연관 키워드 목록
   - 정보성 서술(효능·증상 등)에 사용한 참고자료/출처
   - CTR 높은 제목 후보 20개
   - 추천 해시태그 목록

## 안전장치

- 실행할 때마다 도입부/전개 방식/소제목 표현을 다르게 유도해 매번 다른 글이 나오도록 합니다.
- "완치", "치료된다", "낫는다" 등 의약품 오인·과대광고 표현이 감지되면 실행 후 경고 메시지를
  출력합니다. **경고가 없어도 게시 전에는 반드시 직접 검수해주세요.**
- `"목차"`/`"요약"` 섹션을 제외한 본문 글자 수가 2000자를 초과하면 경고를 출력합니다.
- `"목차"`, `"요약"`, 참고용 정보의 "제목 후보 20개" 섹션이 누락되면 경고를 출력합니다.
- 이 도구는 초안 생성을 도울 뿐이며, 의료/건강 관련 문구의 최종 법적 책임은 게시자에게 있습니다.
